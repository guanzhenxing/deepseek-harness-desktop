**intake 启动轮定性（重要）**：修复全部 launcher 侧缺陷后，探测（候选 `45e4e8f`）推进到真正阻断点——嵌入式运行时的 cordis-plugin-loader 按包名**从自身位置**解析，app bundle 内的 loader 永远走不到 profile 的 node_modules（`ERR_MODULE_NOT_FOUND`）。这是布局设计题（上游补丁或投影进 loader 可达根），非临时缺陷；ADR-0010 已更新。v0.1.0 因此**不声明第三方 bundle 可启动**：链以 `--launch-round=excluded` 演练实际交付的引入能力（校验/装入/字节复验/隔离），启动轮保留在独立命令 `verify:plugin-intake` 的 fail-closed 默认模式（保持红色直到设计落地）。
